# 추천 카탈로그 구축 현황

**SSAFY 15기 · 대전 1반 102팀 · 설계 미팅 자료 · 2026-08-27 기준**

도서 352만 종의 통합 카탈로그를 세우고, 추천 후보 108만 종에 임베딩용 텍스트를 채우는 작업.
텍스트 확보율은 착수 전 5.3%에서 **지금 13.9%**까지 왔고, 3단계 중 1단계의 9.3% 지점에 있다.

이 문서는 **무엇이 확정됐고 무엇이 아직 아닌지**를 구분한다.
수치는 전량 실측이며, 추정치는 근거를 함께 표기했다.

| 통합 카탈로그 L0 | 추천 후보 L1 | 보유 원장 | L1 텍스트 확보 |
| ---: | ---: | ---: | ---: |
| **3,528,013** | **1,082,390** | **121,135,896** | **150,736** |
| 국중 ∪ 정보나루 | 대출 72+ ∪ 신간 | 1,660개관 전수 | 후보의 13.9% |

<br/>

## 1. 지금까지 모은 것

수집이 끝난 자산이다. 여기까지는 재작업 없이 그대로 쓴다.

| 자산 | 규모 | 크기 | 비고 |
| --- | --- | ---: | --- |
| **국립중앙도서관 서지** | 2,047,239행 / 고유 ISBN 2,019,407 | 327 MB | 서지 표준. 원본 JSONL 2.2GB를 Parquet으로 압축 |
| **정보나루 보유 원장** | 121,135,896행 / 1,660개관 | 673 MB | 관 × ISBN × 대출 × 권수. 표본이 아닌 전수 |
| ISBN 합산 대출 | 2,791,309 ISBN / 누적 19.7억 건 | 25 MB | 필터·랭킹·수집 우선순위의 근거 |
| **국중 URL 텍스트 회수** | 191,122건 → 정제 174,388건 | 595 MB | API 호출 0회. 서지에 URL만 있던 본문을 직접 회수 |
| 정보나루 보강 *(진행 중)* | 28,124건 | 18 MB | 1단계 9.3% 지점 |

> **이번 회차의 숨은 성과**
> 국중 URL 회수로 **추천 후보의 텍스트 보유율이 5.3% → 11.8%로 두 배가 됐다.**
> 서지에 본문 대신 `.txt` 파일 주소만 들어 있는 경우가 많은데, 그 파일을 직접 받아왔다.
> 외부 API 쿼터를 한 건도 쓰지 않고 얻은 분량이다.

## 2. 왜 정보나루가 주 보강원인가

당초 계획은 카카오를 주 소스로 두는 것이었다. **층화 파일럿 582건이 이를 뒤집었다.**

층별 description 확보율 — 판정 기준 100자 이상:

| 층 | 모집단 | n | 카카오만 | 정보나루만 | 둘 다 없음 |
| --- | ---: | ---: | ---: | ---: | ---: |
| A · ~2006년 | 146,109 | 102 | 2.0% | **44.1%** | 33.3% |
| B · 2007–14 | 225,178 | 120 | 2.5% | **24.2%** | 13.3% |
| C · 2015년~ | 215,668 | 120 | **5.0%** | 2.5% | 6.7% |
| D · 정보나루 전용 | 329,200 | 120 | 1.7% | **26.7%** | 45.8% |
| **사후층화 종합** | **916,155** | **462** | **50.2%** | **70.7%** | **26.6%** |

비대칭이 결정적이다. **정보나루는 카카오 위에 +23.1%p를 더하는데, 카카오는 정보나루 위에 +2.7%p뿐이다.**
카카오가 이기는 층은 C(신간) 하나이고 격차도 2.5%p다.

이유는 두 소스의 성격 차이다. 카카오는 *현재 유통 중인 상품*의 DB라 절판 구간과 서점 유통망 밖에서
급격히 약해진다. 정보나루는 도서관 장서 기반이라 절판 여부와 무관하다.

→ **정보나루를 주 보강원으로, 카카오는 신간 잔여분 전용으로 강등.**

## 3. 수집 계획 — 3단계

전량을 다 긁기 전에 멈출 수 있다는 전제로 순서를 짰다.
**멈춘 시점까지가 가장 값어치 있어야 한다.**

### 1단계 · 노출 90% 밴드 — 301,154건 `진행 중`

누적 대출이 전체의 90%에 닿을 때까지. 대출 1만 건 이상인 책들.
여기만 끝내도 **이용자가 실제로 마주치는 책의 90%**를 덮는다.

```
████░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  9.3%
28,124 / 301,154 · 남은 9일
```

### 2단계 · 신간 트랙 — 120,877건 `대기`

2025년 이후 발행. 대출 이력이 없어 1단에 못 들지만 추천 품질에는 직결되므로 꼬리보다 앞세운다.

```
░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  0%
0 / 120,877 · 추가 4일
```

### 3단계 · 꼬리 — 532,745건 `보류`

추천 후보 중 나머지. 대출 비중 10% 미만 구간이라 **온디맨드로 돌리는 편이 합리적**이다 —
이용자가 실제로 조회할 때 채운다.

```
░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  0%
0 / 532,745 · 전량 시 추가 18일
```

> **제약 — 일일 3만 호출 (실측 확정)**
>
> 정보나루는 고정 IP 등록 후에도 하루 약 3만 호출이 상한이다. 공식 문서에는 없고 실측으로 확인했다.
> **24,000건까지 정상 → 26,000건에서 조용히 거절 시작 → 31,756건에서 연결 강제 종료.**
> 수집기는 이 지점에서 자동 정지하고 자정에 스스로 재개한다.
>
> 전량 완주는 32일. **1단계에서 끊고 카카오를 병행하는 안(10일)을 권한다.**

## 4. 1단계에서 확인된 것

28,124건은 표본이 아니라 실제 산출물이다. 아래는 그 실측 채움율이다.

| 필드 | 채움율 | 추천에서의 쓸모 |
| --- | ---: | --- |
| 서지 (제목·저자·출판사) | **100.0%** | 헛돈 호출 0건 |
| 표지 이미지 | 96.9% | 서비스 UI |
| 발행연도 | 92.6% | 신선도 부스팅·연도 필터 |
| **소개문 100자 이상** | **90.3%** | 임베딩 입력 — 주 목적 |
| KDC 분류 | 90.0% | 주제 필터 |
| 부가기호 | 93.7% | 아동·전자책 판별 |
| 연령·성별 대출 분포 | ⚠ 10.6% | 인구통계 prior — 상위 구간 한정 |

### 국중 결측을 실제로 메웠는가

| 국중 쪽 결측 | 대상 | 메운 비율 |
| --- | ---: | ---: |
| 서지 자체가 없던 책 | 6,635 | **100.0%** |
| 텍스트가 없던 책 | 19,378 | **90.3%** |
| KDC가 없던 책 | 6,675 | 72.1% |

### 조인이 실제로 성립하는가

4개 소스(정보나루 보강 · 국중 서지 · 국중 회수 텍스트 · 보유 원장)를 ISBN13으로 붙여 검증했다.
**발간일·주제·내용 세 축을 모두 갖춘 행이 79.8%**다.

```
isbn13     9788936434120
title      소년이 온다
author     지은이: 한강
pub_year   2014
kdc        813.62 · 문학 > 한국문학 > 소설
loans      275,515건 · 소장 1,539개관
body       섬세한 감수성과 치밀한 문장으로 인간 존재의 본질을 탐구해온
           작가 한강의 여섯번째 장편소설…
age        청소년 751(전국1위) · 20대 1,371(1위) · 30대 1,574(3위)
gender     20대(여) 513 · 30/40대(여) 1,076 · 20대(남) 216
```

"25세 여성, 한국소설 선호"에 이 책을 올릴 근거가 한 행 안에 전부 들어 있다.

## 5. 완료 시 기대치

추천 후보 L1 (1,082,390건) 기준 텍스트 커버리지:

| 시점 | 건수 | 비율 | 근거 |
| --- | ---: | ---: | --- |
| 보강 착수 전 | 57,101 | 5.3% | 국중 원본 서지만 — 실측 |
| URL 회수 반영 | 127,614 | 11.8% | API 호출 0회로 두 배 — 실측 |
| 현재 (1단계 9.3% 지점) | 150,736 | 13.9% | 실측 |
| 1단계 완료 시 | 399,556 | 36.9% | *추정* — 현재 채움율 90.3% 연장 |
| **정보나루 전량 완료 시** | **802,640** | **74.2%** | *추정* — 파일럿 사후층화 K=70.7% |

세 축 동시 충족률은 **낙관 84.3% · 보수 64.8%**다.
낙관치는 1단계 실측을 끝까지 연장한 값이고, 보수치는 꼬리 구간에 파일럿 확보율을 적용한 값이다.
실제로는 두 값 사이에 떨어진다.

## 6. 설계에 반영해야 할 제약

데이터를 더 모아서 해결되지 않는 것들이다. **아키텍처에서 흡수해야 한다.**

### 이 구조로 되는 것

- **콘텐츠 기반 추천** — 발간일·주제·내용 세 축이 모두 실측으로 확보된다
- **주제 필터** — KDC 3자리 238종, 엔트로피 기준 유효 28종으로 갈린다
- **수요 prior** — 전국 누적 대출 19.7억 건. 국내 최대 규모의 실제 이용 신호
- **인구통계 prior** — 12개 세그먼트, 1위 세그먼트 점유율 중앙 54%로 편중이 뚜렷

### 이 구조로 안 되는 것

- **협업 필터링** — 보유 원장이 *관 단위 집계*라 개인 식별자가 없다.
  누가 A와 B를 함께 빌렸는지가 없으니 user-item 행렬을 만들 수 없다
- **전 카탈로그 인구통계** — 연령·성별 분포는 수요 상위 2천위 33.9%에서
  1만2천위 5.4%로 급락한다. 보조 신호일 뿐이다
- **문체·난이도 매칭** — 소개문 중앙 147자로는 주제는 잡혀도 문장 결은 안 잡힌다

> **가장 중요한 한 가지**
>
> **사용자 행동 데이터가 0건이므로 취향은 온보딩에서 직접 받아야 한다.**
> 좋아하는 책 3~5권을 고르게 하고 그 임베딩 중심을 취향 벡터로 삼는 방식이다.
> 협업 필터링은 서비스를 운영하며 클릭·찜 로그가 쌓인 뒤에 추가할 수 있다.

### 추천 파이프라인 형태

```
온보딩    좋아하는 책 3~5권 → 임베딩 중심 = 취향 벡터
   ↓
검색      취향 벡터 ANN (HNSW)
   ↓
필터      KDC 메타 필터 + 발간연도 밴드
   ↓
랭킹      유사도 × 인구통계 prior × 수요 prior × 신선도
   ↓
로그 축적 → 운영 3개월 후 협업 필터링 추가
```

> **인기 편향 주의**
>
> 수요 상위일수록 데이터 품질이 좋다 — 소개문 확보율이 1단계 90.3%인 반면 꼬리 구간 파일럿은 52.5%였다.
> 아무 조치도 안 하면 추천이 자연히 베스트셀러로 쏠린다.
> **명시적 novelty 페널티가 없으면 "추천"이 아니라 "인기순"이 된다.**

## 7. 미팅에서 정할 것

| 안건 | 선택지 | 권고 |
| --- | --- | --- |
| **수집 범위** | 1단계 완주(10일) / 전량(32일) | **1단계 + 카카오 병행** — 노출 90%를 10일에 덮고 꼬리는 온디맨드 |
| **취향 입력 방식** | 온보딩 도서 선택 / 장르 선택 / 없음 | **도서 선택** — 협업 필터링이 불가하므로 이것이 유일한 취향 신호다 |
| **임베딩 시점** | 전량 사전 / 후보군 한정 / 온디맨드 | 후보군 한정 — 108만 종 × 768차원이면 GPU 메모리에 들어간다 |
| **인구통계 활용** | 랭킹 반영 / 미사용 | 상위 구간에만 가중 반영. 10.6%뿐이라 전면 적용은 불가 |
