## 1. 방향 검증 — 실제 사람들의 행동과 맞는가

**정답을 분류표가 아니라 행동에서 가져왔다.**
정보나루 `coLoanBooks`는 실제로 같은 이용자가 이어서 빌린 책이다.
임베딩 추천이 그것과 얼마나 겹치는지를 잰다.

> **먼저 — 앞선 지표 선택의 정정**
>
> 이 검증의 첫 판에서는 **KDC 세부분류 적중률**을 주 지표로 썼다.
> 그것은 "텍스트가 주제 신호를 담는가"를 재는 데는 맞지만
> **"좋은 추천인가"를 재는 데는 맞지 않는다.**
> *소년이 온다*를 좋아하는 사람이 반드시 한국소설을 더 원한다는 보장이 없다.
> 아래는 행동 기반 지표로 다시 잰 결과다. KDC는 참고 열로만 남긴다.

평가 대상 11,743권 · 정답(함께대출·마니아추천·다독자추천) 147,647건:

| 입력 구성 | 적중@5 | 적중@10 | 재현@20 | 정답 순위 | *참고* KDC |
| --- | ---: | ---: | ---: | ---: | ---: |
| **키워드** | **31.7%** | **23.9%** | **30.6%** | **126위** | *61.7%* |
| 제목 + 소개문 + 키워드 | 30.4% | 22.8% | 29.0% | 147위 | *57.7%* |
| 제목 + 소개문 | 30.0% | 22.6% | 28.6% | 156위 | *57.3%* |
| 소개문 (카카오) | 25.3% | 18.9% | 23.2% | 258위 | *48.3%* |
| 소개문 (정보나루) | 24.6% | 18.2% | 23.0% | 202위 | *53.5%* |
| 제목만 | 22.4% | 17.6% | 24.3% | 257위 | *45.3%* |
| **[무작위]** | **0.097%** | — | — | — | *10.3%* |

> **방향은 맞다**
>
> **무작위의 247배.** 임베딩 상위 10권 중 2.4권이 실제로 사람들이 함께 빌린 책이다.
> 우연으로 나올 수 없는 수치다.
> **텍스트로 이용 패턴을 상당 부분 복원할 수 있다**는 뜻이고,
> 임베딩 기반 추천이라는 방향 자체는 검증됐다.

> **그러나 단독으로는 부족하다**
>
> 적중@10이 23.9%면 **10권 중 7.6권은 사람들이 함께 빌리지 않는 책**이다.
> 정답이 임베딩 순위에서 놓이는 자리도 중앙 **126위**다.
> 협업필터링 신호가 있는 구간에서는 그쪽을 우선해야 한다.

두 지표의 **순위가 대체로 일치**한다는 점도 중요하다.
행동으로 봐도 분류로 봐도 `키워드 > 소개문+키워드 > 소개문 > 제목만`이다.
앞선 결론(키워드가 값어치 있다 · 제목만으로는 부족하다)은 행동 지표로도 유지된다.

> **이 지표의 한계도 밝힌다**
>
> 정답 234,626건 중 **수집분 안에 있는 것은 62.9%**다.
> 나머지는 아직 안 모은 책이라 맞힐 방법이 없다 — 수집이 진행되면 수치가 오른다.
> 그리고 `coLoanBooks`는 **평균적 이용자의 행동**이지 특정 사용자의 취향이 아니다.
> 진짜 답은 서비스 운영 후 클릭·찜 로그에서만 나온다.

### 보조 검증 — 텍스트가 주제 신호를 담는가

이쪽은 **표현이 제대로 만들어졌는지 확인하는 바닥 검사**다.
텍스트만으로 사서가 매긴 분류를 복원하지 못하면 애초에 주제를 인코딩하지 못한 것이다.
입력에서 제목·저자·KDC를 빼고 소개문 본문만 넣어 쟀다.

| 입력 구성 | 적중률 | 무작위 대비 | 평균 길이 |
| --- | ---: | ---: | ---: |
| 정보나루 + 카카오 | **56.8%** | 5.5배 | 397자 |
| 카카오 단독 | 54.2% | 5.3배 | 237자 |
| 정보나루 단독 | 53.0% | 5.2배 | 158자 |
| *[기준선] 제목만* | *48.7%* | *4.7배* | *16자* |
| **[기준선] 무작위** | **10.3%** | 1.0배 | — |

바닥 검사는 통과했다 — 무작위의 5.5배다.
다만 **제목만으로도 48.7%**가 나오므로 소개문 397자의 순수 기여는 +8.1%p다.
한국어 도서 제목이 그 자체로 주제를 많이 담기 때문이다.

## 2. 정성 — 실제 추천 결과

지표가 좋아도 결과가 엉뚱하면 소용없다. 실제로 뽑아 봤다.
`◎` 세부분류 일치 · `○` 대분류 일치 · `✗` 오답

### 잘 되는 경우 — 작가·장르 단위

```
질의  나미야 잡화점의 기적 · 히가시노 게이고 · 일본소설        [5/5 적중]
  1. ◎ 그대 눈동자에 건배        히가시노 게이고    0.765
  2. ◎ 거울 속 외딴 성          츠지무라 미즈키    0.731
  3. ◎ 새벽 거리에서            히가시노 게이고    0.721
  4. ◎ 흑뢰성                 요네자와 호노부    0.706
  5. ◎ 라플라스의 마녀          히가시노 게이고    0.702
```

같은 작가 3권 + 같은 결의 일본 미스터리 2권. 서점 직원이 골라줄 법한 목록이다.
`부의 추월차선`도 같은 저자 후속작이 1위로 올라오며 재테크 도서로 정확히 모였다.

### 애매한 경우 — 주제는 맞지만 결이 어긋난다

```
질의  미드나잇 라이브러리 · 매트 헤이그 · 영미소설             [오답 2건]
  1. ◎ 시간을 멈추는 법          매트 헤이그       0.689
  2. ◎ 리틀 라이프             한야 야나기하라    0.669
  3. ✗ 글의 품격              이기주 — 글쓰기 에세이  0.663
  4. ◎ 운명과 분노             로런 그로프       0.660
  5. ✗ 유혹하는 글쓰기          스티븐 킹 — 글쓰기론   0.653
```

실패 원인이 명확하다. **제목의 "라이브러리"가 '책·글쓰기' 쪽으로 끌어당겼다.**
분류 일치는 5/10인데 체감 정확도는 그보다 낮다.

### 실패하는 경우

```
질의  사피엔스 (그래픽노블판) · 세계사                    [사실상 전부 오답]
  1. ✗ 이집트 피라미드에서 살아남기   학습만화         0.666
  2. ✗ 정재승의 인류 탐험 보고서                     0.631
  3. ✗ 진시황릉에서 살아남기       학습만화         0.629
  4. ○ 역사란 무엇인가           E.H. 카        0.615
  5. ✗ 식물 세계에서 살아남기 2     학습만화         0.614
```

> **원인 두 가지 — 둘 다 데이터 쪽이다**
>
> **① 원작 『사피엔스』가 아직 수집되지 않았다.**
> 1단계의 9.3%만 모은 상태라 잡힌 것은 그래픽노블판이다.
>
> **② 그 소개문이 내용이 아니라 책의 형식을 설명한다.**
> "…기발한 각색과 세련된 그림을 통해 재탄생한 *그래픽노블의 걸작*이다."
> — 인류사 이야기가 한 줄도 없다. 그래서 '학습만화' 신호로 임베딩돼
> `~에서 살아남기` 시리즈와 붙었다. 이런 판형 설명형 소개문이 전체의 3.1%다.

## 3. 이번에 잡은 구조적 결함 — 시리즈물

가장 큰 문제였고, **지표로는 전혀 드러나지 않았다.**

```
질의  수학도둑 · 송도수 · 수학 학습만화          [수정 전 · 10/10이 같은 시리즈]
  1. ✗ 수학도둑 71                          0.943
  2. ✗ 수학도둑 51                          0.936
  3. ✗ 수학도둑 81                          0.931
  4. ✗ 수학도둑 49                          0.928
  5. ✗ 수학도둑 50 · 58 · 80 · 15 · 1 · 2 …    0.926 ↓
```

권차가 **제목 안에** 박혀 있어(`수학도둑 71` vs `수학도둑 51`)
제목 기준 중복 제거로는 걸리지 않았다. 소개문이 권마다 거의 같아 유사도가 0.92를 넘는다.

```
질의  수학도둑 · 권차 병합 적용 후                   [다른 저자 도서 진입]
  1. ◎ 수학도둑                  송도수         0.876
  3.   수학자 납치사건             정완상         0.814
  6. ◎ 수학 이야기                사쿠라이 스스무   0.794
  7.   초 재밌어서 밤새읽는 수학이야기   사쿠라이 스스무   0.791
```

제목에서 권차·부제를 떼어 시리즈 단위로 묶으니 **27,196권 → 21,849권(19.7% 감소)**이 되고
다른 저자의 수학 학습만화·교양서가 올라오기 시작했다.
`소년이 온다`도 분류 일치가 **40% → 69%**로 올랐다.

> **설계 반영 필수**
>
> 권차가 제목에 박힌 시리즈는 별도 처리가 반드시 필요하다.
> 100권 넘는 학습만화가 대출 상위에 많아, 안 하면
> **아동 도서 추천이 전부 한 시리즈로 도배된다.**

## 5. 임베딩보다 나은 신호가 있다

정보나루 `usageAnalysisList`가 **함께 대출된 도서**를 제공한다.
같은 질의를 이것으로 뽑으면 결과가 다르다.

```
질의  미드나잇 라이브러리 · 정보나루 함께 대출된 도서          [전부 적중]
  1. 불편한 편의점               김호연
  2. 달러구트 꿈 백화점            이미예
  3. 어서오세요, 휴남동 서점입니다     황보름
  4. 아버지의 해방일지             정지아
  5. 밝은 밤                   최은영
```

**'힐링 판타지·위로 소설' 클러스터를 정확히 짚는다.**
임베딩이 오답 2건을 낸 자리에서 이것은 전부 맞다.
마니아 추천에서는 매트 헤이그의 다른 작품 3권이 올라온다.

> **앞선 판단의 정정**
>
> 이전 보고서에 **"협업 필터링 — 이 구조로 안 되는 것"**이라고 적었으나 정확하지 않았다.
> 보유 원장에 개인 식별자가 없어 *우리가 직접 만들 수는 없지만*,
> 정보나루가 이미 계산해 API로 제공한다. 같은 1회 호출에 딸려 온다.

함께대출 신호의 구간별 보유율 (표본 600건):

| 큐 구간 | 함께대출 | 키워드 | 주 신호 |
| --- | ---: | ---: | --- |
| 상위 1~1만 | **99%** | 94% | 협업필터링 |
| 1만~5만 | **98%** | 88% | 협업필터링 |
| 5만~15만 | 87% | 66% | 협업필터링 |
| 15만~30만 (1단계 끝) | 64% | 24% | 혼합 |
| 꼬리 | 46% | 6% | 혼합 |
| **신간 (2025+)** | **19%** | **2%** | **임베딩** |

**신간은 대출 이력이 없어 협업필터링이 19%뿐이다.**
바로 여기가 임베딩이 반드시 필요한 자리다. 두 신호는 경쟁이 아니라 상호 보완이다.

## 6. 무엇을 썼는가 — 모델과 방식

이 보고서의 모든 수치는 아래 구성으로 낸 것이다.

| 요소 | 선택 | 이유 |
| --- | --- | --- |
| **임베딩 모델** | `jhgan/ko-sroberta-multitask` | 한국어 문장 임베딩. KorNLI·KorSTS 학습, 768차원, 약 1.1억 파라미터. RTX 4070 6GB에 여유 |
| 입력 구성 | 제목 + 정보나루 소개문 + 카카오 소개문 | 실험에서 이 순서(D+K)가 1위. 중앙 202자 ≈ 91토큰 |
| 유사도 | 코사인 (정규화 후 내적) | 문장 임베딩의 표준. 길이 차이에 영향받지 않음 |
| 탐색 | 현재 전수 내적 / 운영은 HNSW | 2.2만 권은 전수로 충분. 95만 권에서는 ANN 필요 |
| **추천 방식** | 콘텐츠 기반 + 협업필터링 혼합 | 임베딩은 내용 유사, 함께대출은 이용 패턴. 서로 다른 축 |

> **밝혀둘 한계 — 모델을 비교하지 않았다**
>
> 사전 등록 프로토콜에 **"모델은 하나만 쓴다"**고 못박았다.
> 여러 모델을 돌려 좋은 결과를 고르면 그것은 실험이 아니기 때문이다.
> 따라서 `ko-sroberta-multitask`가 최선이라는 근거는 **없다.**
> 다만 *텍스트 구성 간 비교*는 모델을 고정했으므로 유효하다.

## 7. 핵심 기능 검증 — 취향 여러 권으로 추천하기

온보딩에서 책 3~5권을 받아 추천하는 것이 서비스의 주 동작이다.
**여러 권을 어떻게 하나로 합칠지**가 문제이고, 여기서 갈렸다.

| 취향 조합 | 흩어짐 | 중심(평균) | 최대 | 합산 | 교대 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 한 작가에 몰림 | 0.72 | 100% | 100% | 100% | 100% |
| 한 장르 안에서 흩어짐 | 0.47 | 83% | 83% | 83% | 83% |
| 장르를 가로지름 | 0.30 | 67% | 83% | 67% | 67% |
| **완전히 흩어짐** | 0.41 | **17%** | 83% | **17%** | 67% |

> **가장 흔한 방식(벡터 평균)이 가장 먼저 무너진다**
>
> 취향이 흩어지면 평균 벡터가 **아무것도 아닌 지점**에 떨어진다.
> `미드나잇 라이브러리 + 수학도둑 + 미움받을 용기 + 그리스 로마 신화`로
> 추천했더니 *고전의 숲 · 전지적 독자 시점 · 셰익스피어 비밀 찾기*가 나왔다.
> 네 취향 중 **어느 것과도 관계없다.**

> **최대(max-sim)는 무너지진 않지만 한 권이 독점한다**
>
> 같은 입력에서 **추천 6칸을 수학도둑 시리즈가 전부 차지했다**(유사도 0.94).
> 지표(83%)만 보면 좋아 보이지만 실제로는 못 쓴다.

**해법 — 취향책마다 따로 뽑아 번갈아 채운다.**
하나의 점수로 접지 않는 것이 요점이다. 접는 순간 무너지거나 독점된다.

```
소년이 온다 + 부의 추월차선 + 총, 균, 쇠      (흩어짐 0.30, 교대 방식)

  1. ◎ 여우야 여우야 뭐하니      ← 소년이 온다
  2. ○ 부의 추월차선(동명이서)    ← 부의 추월차선
  3.   문명의 붕괴             ← 총, 균, 쇠  (같은 저자)
  4. ◎ 소년이로               ← 소년이 온다
  5.   레버리지               ← 부의 추월차선
  6. ◎ 총, 균, 쇠             ← 총, 균, 쇠
                             배분: 2칸 · 2칸 · 2칸
```

같은 입력에서 중심(평균)은 *광인 · 열국지 · 토정비결*을 냈다. 관계없는 목록이다.

> **이 표의 숫자를 그대로 믿지 말 것**
>
> "교대 67% < 최대 83%"로 보이지만 **지표가 이 경우를 잘못 평가한다.**
> 지표는 "취향책과 KDC가 같은 비율"을 세는데, 세 장르를 골고루 덮으면
> 각 장르가 1/3씩이라 점수가 낮게 나온다. 한 시리즈로 도배해도 점수는 높다.
> **목록을 봐야 판단이 된다.**

## 8. 키워드 — 태그로는 못 쓰지만 임베딩에는 값어치가 있다

정보나루가 책당 키워드 50개를 준다(보유율 94%). 두 용도를 나눠 판정해야 한다.

### 태그 UI로는 못 쓴다

| 구간 | 개수 | 실제 내용 |
| --- | ---: | --- |
| 최빈 30개 | 30 | 사람 · 아이들 · 어린이 · 시리즈 · 세계 · 사랑 · 그림 · 다양 · 독자 · 마음 |
| 100권 이상 등장 | 386 | 비밀 · 미국 · 내용 · 구성 · 생활 · 누구 · 공부 · 방법 · 등장 · 소개 |
| **1회만 등장** | **26,285** | 전체의 58%. 등장인물 이름(영혜·인혜·윌리)과 작품 제목 |

**본문 빈도 기반 추출어이지 큐레이션된 태그가 아니다.**
사용자가 고를 태그는 **KDC와 부가기호로 직접 만들어야 한다.**

### 그러나 임베딩 입력으로는 소개문보다 낫다

KDC 세부분류 적중률@10 · 표본 8,734권 · 잡음 폭 2.45%p:

| 입력 구성 | 적중률 | 소개문 대비 | 평균 길이 |
| --- | ---: | ---: | ---: |
| 키워드 원본만 | 62.6% | +7.8%p | 200자 |
| **소개문 + 키워드 원본** | **60.4%** | +5.6%p | 358자 |
| **소개문 + 키워드(정제)** | **60.0%** | +5.2%p | 334자 |
| 키워드만 (정제) | 58.7% | +3.9%p | 176자 |
| 소개문만 *(기준)* | 54.8% | — | 157자 |

> **처음 본 +7.8%p의 절반은 착시였다**
>
> 키워드에 **출판사명이 75.3%, 저자명이 89.9%, 자기 제목이 86.1%** 섞여 있다.
> 출판사는 분야가 편중돼 있어(비룡소=아동, 창비=문학) 같은 출판사끼리 뭉치고,
> 그것이 KDC 적중률을 부풀린다. **주제를 맞힌 것이 아니라 출판사를 맞힌 것이다.**
>
> 서지어를 걷어내니 순증이 **+7.8%p → +3.9%p**로 줄었다.
> 그래도 잡음 폭 2.45%p를 넘으므로 **진짜 신호가 남아 있다.**
> 실서비스에는 `소개문 + 정제 키워드`를 쓰는 것이 안전하다.

> **다만 이것은 "주제"이지 "느낌"이 아니다**
>
> KDC 적중률이 오른 것은 **주제 판별력**이지 분위기 판별력이 아니다.
> `미드나잇 라이브러리`를 키워드로 추천하면
> *그레이의 50가지 그림자 · 호스트 · 천사가 된 비키*가 나온다 —
> 영미소설이라는 주제는 맞지만 '힐링 판타지'라는 결은 아니다.
> **분위기 축은 여전히 재료가 없다.**

## 9. 랭킹 feature 5종 — 지금 데이터로 되는가

기획된 개인화 축 다섯 개를 실제 데이터로 계산해 봤다.
**재료는 다 있는데 두 개는 그대로 쓰면 작동하지 않는다.**

수요 상위 구간 6,886권 기준 (신간·꼬리에서는 `coLoan`이 19~46%로 급락):

| Feature | 재료 | 보유율 | 판정 |
| --- | --- | ---: | --- |
| `taste` | 소개문 + 키워드 → 임베딩 | 95.0% | **작동** |
| `coLoan` | 함께 대출된 도서 10건 | 99.5% | **작동** |
| `trending` | 월별 대출 12개월 | 98.4% | ⚠ 보정 필수 |
| `steady` | 월별 대출 12개월 | 98.4% | ⚠ 재설계 필요 |
| `newField` | KDC — 난이도 재료 없음 | 93.8% | ✗ 부분 불가 |

> **trending — 원시값으로 쓰면 98.8%가 "하락"으로 찍힌다**
>
> 뚜렷한 상승은 **1.2%뿐**이다. 원인은 명확하다 —
> **전체 대출량 자체가 12.3% 감소 중**이다 (권당 월평균 318 → 244).
> 절대 증감은 의미가 없으므로 **동시기 전체 대비로 상대화하거나 백분위로 변환**해야 한다.
>
> 더 고약한 것은 계절성이다. 하락 상위 4권이 전부 계절 도서였다 —
> *가을을 만났어요 · 크리스마스 선물 · 분홍 토끼의 추석 · 메리 크리스마스, 늑대 아저씨!*
> 수집 시점이 8월이라 겨울·가을 책이 전부 하락으로 잡혔다.
> **전년 동월 대비로 계산해야 한다.**

> **steady — 변별력이 없다**
>
> **95%가 "꾸준함" 이상**이고 표준편차가 0.064다. 순위를 못 바꾼다.
> 12개월 월별 대출은 원래 안정적이기 때문이다.
> **"오랫동안"을 12개월로 재려 한 것이 문제다.**
> 발행연도(중앙 2011년)와 누적대출(보유율 100%)을 함께 써서
> *연식 대비 여전히 빌려지는가*로 재야 한다.

> **newField — "도전해볼 만한가"의 재료가 없다**
>
> "새로운 분야인가"는 KDC로 된다. 그러나 **난이도 신호가 없다.**
> 가장 가까운 부가기호 독자대상은
> `아동 64.9% · 교양(일반) 24.0% · 학습참고 4.7% · 전문 0.2%`인데,
> 이것은 **대상 연령이지 난이도가 아니다.**
> 같은 "교양(일반)" 안에서 *지대넓얕*과 *총, 균, 쇠*를 못 가른다.

## 10. 권고 구조

```
온보딩     좋아하는 책 3~5권 → 취향 벡터
   ↓
후보 생성   협업필터링(함께대출)  ─┐
           임베딩 ANN           ─┴→ 합집합
   ↓
중복 제거   시리즈·판본 병합          ← 없으면 한 시리즈로 도배된다
   ↓
필터       KDC + 발간연도 밴드
   ↓
랭킹       협업필터링 우선 · 임베딩 유사도 · 수요 prior · 신선도
           + novelty 페널티          ← 없으면 "추천"이 아니라 "인기순"이 된다
   ↓
로그 축적 → 자체 협업필터링으로 전환
```

| 구간 | 주 신호 | 근거 |
| --- | --- | --- |
| 수요 상위 (~15만위) | **협업필터링** | 보유율 87~99%. 실제 결과가 임베딩보다 확실히 낫다 |
| 신간 | **임베딩** | 협업필터링 19%. 대체 수단이 없다 |
| 꼬리 | 혼합 | 협업필터링 46%. 있으면 우선, 없으면 임베딩 |

> **읽을 때 유의할 것**
>
> 현재 추천 대상은 **21,849권으로 전체 계획(95만)의 2.3%**다.
> 사피엔스처럼 원작이 아직 없어 실패하는 경우가 지금은 많고,
> 수집이 진행되면 상당수 해소된다.
> 또한 표본이 수요 상위에 치우쳐 있어 **여기 수치는 상한으로 읽어야 한다.**

## 11. 미팅에서 정할 것

| 안건 | 권고 |
| --- | --- |
| **추천 엔진 구조** | **협업필터링 우선 + 임베딩 보완** — 임베딩 단독은 품질 미달 |
| **시리즈 중복 제거** | **필수 적용** — 없으면 아동 도서가 한 시리즈로 도배된다 |
| **취향 합치기 방식** | **교대(취향별 번갈아)** — 벡터 평균은 흩어진 취향에서 무너진다 |
| **태그 기능** | **KDC + 부가기호로 직접 만들 것** — 정보나루 키워드는 라벨로 못 쓴다 |
| **임베딩 입력에 키워드 추가** | 소개문 + 정제 키워드 — 적중률 54.8% → 60.0% |
| **trending 정의** | 동시기 상대화 + 전년 동월 대비 — 원시 증감은 98.8%가 하락 |
| **steady 정의** | 12개월 대신 발행연도 + 누적대출 — 현재 정의는 변별력 없음 |
| newField 의 난이도 축 | 재료 없음. 빼거나 LLM 분류 공정을 별도로 세울 것 |
| **추천 품질 지표** | **함께대출 적중률을 쓸 것** — KDC 적중은 추천 품질이 아니다 |
| 임베딩 모델 비교 | 미실시. 다른 모델로 결과가 달라지는지 별도 확인 필요 |
| 판형 설명형 소개문 | 앞머리 패턴 필터링 여부 — 3.1%, 우선순위는 낮음 |
