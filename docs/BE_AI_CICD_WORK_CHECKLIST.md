# BE · AI · CI/CD 작업 순서 체크리스트

이 문서는 백엔드, AI, CI/CD 담당자가 Jira 업무를 선행 의존성에 맞춰 진행하고 인수인계하기 위한 공용 체크리스트다.

- Jira 프로젝트: `S15P21B102`
- 기준 브랜치: `dev`
- 작업 브랜치: `feature/S15P21B102-{이슈번호}-{간단한-설명}` 또는 팀 브랜치 규칙
- 담당자는 Jira와 아래 체크란에 작업을 시작할 때 기록한다.
- 선행 이슈가 모두 완료된 업무만 시작한다.
- 완료 시 코드, 테스트, 문서, Jira 상태와 PR 링크를 함께 갱신한다.

## 사용 방법

각 업무를 시작할 때 아래 항목을 채운다.

```text
담당자: 
브랜치: 
PR: 
시작일: 
완료일: 
```

체크 상태의 의미는 다음과 같다.

- `[ ]`: 시작 가능 여부 확인 전 또는 미착수
- `[-]`: 진행 중
- `[x]`: 테스트와 리뷰까지 완료
- `[!]`: 선행 작업 또는 외부 결정으로 중단

## 전체 실행 흐름

```text
BE 공통 기반
  -> 검색·인증·서재
  -> AI 입력 기반
  -> AI 후보 생성
  -> 추천 저장·행동 수집
  -> 콜드스타트·개인화
  -> AI-BE 통합 및 품질 검증
  -> 서비스별 컨테이너 이미지
  -> 자동 배포·롤백
  -> 최종 운영 점검
```
