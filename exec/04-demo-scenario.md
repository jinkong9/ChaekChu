# 4. 시연 시나리오

시연 순서에 따라 사이트 화면, 클릭 위치, 예상 결과와 설명 포인트를 정리한다. 소요 시간은 약 3분이다.

## 4.1 사전 준비

| 항목 | 내용 |
|---|---|
| 창 구성 | 창 A: 시크릿 창의 신규 사용자(User1). 로그인 쿠키 없이 랜딩에서 시작<br>창 B: 기존 사용자(User2)가 로그인된 일반 창 |
| User1 (신규) | 가입 이력이 없는 카카오 또는 Google 계정. 로그인과 온보딩 완료까지 시연 |
| User2 (기존) | 과학·경제·경영 도서 10권 이상을 완독 처리하고, 2026년 완독일·별점·한 줄 감상을 기록. 찜한 책도 준비 |
| 시연 데이터 | 홈 인기도서와 검색 색인이 준비되어 있고, User2의 서재·추천·BOOK DNA 결과가 화면에 표시되는지 사전 확인 |
| 시연 흐름 | [User1] 랜딩 → 로그인 → 온보딩 3단계 → 홈 도착<br>[User2] 홈 → 도서 상세 → 홈 Grid view → 오늘의 책추 → 더 많은 추천 → 내 서재(읽음·완독 연표·찜) → BOOK DNA → 가챠 |

## 4.2 신규 사용자 (User1 · 창 A) — 로그인 · 온보딩

| # | 화면 (URL) | 실행 (클릭 위치) | 결과 | 설명 포인트 |
|---|---|---|---|---|
| 1 | 랜딩<br>`/` | 화면 가운데 「카카오로 시작하기」 또는 「Google로 시작하기」 클릭 | OAuth 로그인 후 온보딩으로 이동 | 별도 회원가입 없이 소셜 로그인 |
| 2 | 온보딩 STEP 1<br>`/onboarding` | 닉네임 입력 → 생년월일의 연·월·일 선택 → 성별 선택 → 하단 「다음 →」 클릭 | STEP 2로 이동 | 연령·성별은 첫 추천의 연령·성별 인기도 구간에 사용 |
| 3 | 온보딩 STEP 2<br>`/onboarding` | 「어떤 분야에 관심이 있으세요?」에서 「#소설」·「#에세이」 선택 → 「다음 →」 클릭 | STEP 3으로 이동 | 관심 장르 태그를 선택해 초기 취향 설정 |
| 4 | 온보딩 STEP 3<br>`/onboarding` | 읽어본 책 표지 2권 클릭 → 각 책 아래 별점 선택 → 「완료하고 시작하기 →」 클릭 | 홈 화면 도착 확인 | 선택한 책에 별점을 남겨 취향을 설정<br>신규 사용자 시연은 여기까지 진행하고 창 B로 전환 |

## 4.3 기존 사용자 (User2 · 창 B) — 홈 · 상세 · 추천

| # | 화면 (URL) | 실행 (클릭 위치) | 결과 | 설명 포인트 |
|---|---|---|---|---|
| 5 | 홈 (Ring view)<br>`/home` | 인기도서 링을 좌우 드래그 → 표지 하나 클릭 → 가운데 미리보기 클릭 | 도서 상세로 이동 | 세대별 인기도서를 표지 링으로 탐색 |
| 6 | 도서 상세<br>`/books/:bookId` | 표지·서지 정보와 「책 소개」 확인 → 아래로 스크롤해 「비슷한 책」·「함께 대출된 책」 가리키기 → 「읽고 싶어요」·「읽었어요」 버튼 설명 → 상단 「홈」 클릭 | 홈으로 복귀 | 도서관 대출 카드를 닮은 상세 화면. 비슷한 책·함께 대출된 책으로 다음 독서를 탐색하고 서재에 바로 기록 |
| 7 | 홈 (Grid view)<br>`/home` | 상단 「Grid view +」 클릭 → 연령·성별 구간별 인기도서 훑기 → 「책 추천받기」 클릭 | 추천 화면으로 이동 | 링 대신 목록으로 한눈에 탐색. 필요하면 「Ring view +」로 복귀 |
| 8 | 오늘의 책추<br>`/recommend` | 우표 5장에 마우스를 올려 표지 확인 → 한 장 클릭해 펼치기 → 카드의 추천 이유 가리키기 | 선택한 추천 카드가 위로 올라옴 | 과학·경제 분야 독서 기록과 선호가 반영된 추천 5권, 책별 추천 이유 |
| 9 | 오늘의 책추<br>`/recommend` | 하단 「더 많은 추천」 클릭 | 새 5권으로 교체 | 서재에 이미 있거나 앞서 추천된 책을 제외한 다음 책 묶음 |

## 4.4 기존 사용자 (User2 · 창 B) — 내 서재 · BOOK DNA · 가챠

| # | 화면 (URL) | 실행 (클릭 위치) | 결과 | 설명 포인트 |
|---|---|---|---|---|
| 10 | 내 서재 · 읽음<br>`/library` | 상단 「내 서재」 클릭 → 왼쪽 위 「읽음」 선택 → 펼친 책의 장을 넘기며 완독 기록 확인 | 왼쪽 표지, 오른쪽 제목·별점·한 줄 감상으로 책 기록 표시 | 완독 기록을 개인 책장처럼 보관하고 별점과 짧은 감상을 남김 |
| 11 | 내 서재 · 완독 연표<br>`/library` | 펼친 책 아래 「완독 연표」까지 스크롤 → 2026년 월별 표지 확인 → 표지 하나 클릭 | 해당 책의 기록으로 이동 | 연도별 완독 흐름을 월별 책 표지로 확인 |
| 12 | 내 서재 · 찜<br>`/library` | 왼쪽 위 「찜」 클릭 | 찜한 책 수와 장르별 선반 표시 | 읽고 싶은 책을 장르별로 모아 둠 |
| 13 | BOOK DNA<br>`/dna` | 상단 메뉴 「BOOK DNA」 클릭 → 레이더 차트 확인 → 독서 타입 이름에 마우스를 올리기 | 독서 타입 설명과 5개 지표 확인 | 몰입·감성·새로움·현실감·사색 지표로 독서 경향을 요약 |
| 14 | 책 가챠<br>`/dna?play=gacha` | DNA 화면의 「더 깊이 보는 테스트」에서 「완전 랜덤 책 가챠」 클릭 → 「손잡이 돌리기」 클릭 | 추천 후보에서 무작위 책 한 권 공개 | 취향 기반 추천에서 벗어나 뜻밖의 책 발견 |
| 15 | 가챠 결과<br>`/dna?play=gacha` | 결과 표지에 마우스를 올려 「상세 보기 →」 확인 → 「읽고 싶어요」 클릭 | 내 서재 찜 목록에 추가 | 발견한 책을 바로 읽고 싶은 책으로 저장 |

## 4.5 진행 메모

- 창 A는 실제 신규 OAuth 계정으로 준비하고, 온보딩이 끝나면 창 B로 전환한다.
- 창 B는 기존 사용자의 기록이 보여야 하므로 완독일·평점·감상·찜과 추천 결과를 미리 확인한다.
- 홈 화면의 현재 구현 경로는 `/home`이다. 도서 상세 경로 매개변수는 코드에서 `bookId`로 받는다.
- 시연 직전 웹·백엔드·FastAPI health, 인기 도서 표시, 검색 결과, 추천·DNA 결과를 확인한다.
